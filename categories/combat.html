Build Order

  1. Choose a Martial Path and learn its two-weapon loop.
  2. Add Inner Ways that reinforce the path's actual trigger.
  3. Choose Mystic Skills for missing control, mobility, support or burst.
  4. Equip a gear set whose 4-piece bonus you can activate consistently.
  5. Tune the result for PvE, PvP or support.
