Martial Arts

Weapon styles organized by Martial Path. Each style has its own editable page and a dedicated icon slot.
Adding icons: upload the image using the Martial Art slug, for example assets/icons/martial-arts/nameless-sword.png. The fallback letters disappear automatically when the image exists.
How this database is organized: the two styles inside each card share a Martial Path and are usually designed to work together. Unlock sources can differ between weapon ownership and Martial Art mastery.

Choosing a Pair

Staying inside a Martial Path is the easiest way to build around shared resources and trigger conditions. Hybrid weapon bars can still work when a second style covers healing, range, defense or crowd control.
