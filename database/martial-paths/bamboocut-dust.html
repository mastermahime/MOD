Martial Path · Setup / Burst

Bamboocut - Dust

BD

A swap-heavy Martial Path that moves between mid-range Umbrella setup and Rope Dart burst. Everspring Umbrella creates pressure, grouping and positioning opportunities, then Unfettered Rope Dart converts those openings into Soulbreak-driven damage.

Related Weapons: Everspring Umbrella and Unfettered Rope Dart.

Strengths

  • Burst
  • Mobility
  • AoE

Weaknesses

  • Rotation Complexity
  • Passive Defense
  • Mistimed Burst Windows

Martial Arts

Bamboocut - Dust rewards clean weapon swaps and timing. The Umbrella prepares the field; the Rope Dart applies and cashes out its own debuff loop.

EU

Everspring Umbrella

Umbrella · Mid-Range Setup / AoE

The setup half of the path, using phantom-umbrella pressure, movement and layered AoE to prepare an opening.

CW
Cyclone Waltz

A key Umbrella pressure technique used within the path's mid-range setup and movement loop.

SS
Scarlet Spin

Creates a mobile Umbrella pressure state that rewards timing and clean catches during the rotation.

DB
Dreamwrought Bubbles

Creates a Phantom Umbrella at range, giving Everspring additional positioning and setup options.

UR

Unfettered Rope Dart

Rope Dart · Burst / Debuff

The damage-conversion half of the pair, stacking Soul Loss into Soulbreak before using its stronger payoff skills.

SW
Soul Sweep

Enters Soulbound, applies Soul Loss and drives the weapon toward Soulbreak so later attacks can hit harder.

BB
Burn and Bury

Cash-out damage for targets affected by Soul Loss or Soulbreak, with additional value against properly prepared bosses.

DF
Dart Song Fills the Wild

A charging stance whose payoff changes with charge duration, offering empowered offense or recovery utility.

Same Path, different skillsets: Everspring Umbrella controls range and setup while Unfettered Rope Dart handles debuff stacking and burst. The path feels strongest when both halves are used as one rotation.
