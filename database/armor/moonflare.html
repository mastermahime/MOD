Moonflare Set

Defend-and-attack set that periodically creates an HP shield or heals if one already exists.
2-Piece ThemeMax HP
4-PieceAttacking while defending can create a Max-HP-based shield. If you already have a shield, the proc restores HP instead.

Ideal Use

Designed for frontline paths that keep attacking while actively defending, especially Thundercry Blade / Stormbreaker Spear styles.
