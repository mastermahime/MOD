How Set Bonuses Work

Offensive sets occupy weapon and accessory slots, while defensive sets use the four armor pieces. Two matching pieces activate the smaller bonus and four matching pieces unlock the defining mechanic.

Localization has changed some names across versions and community references. The database keeps Global terminology where verified and a familiar alternate name when it helps players find the set.
