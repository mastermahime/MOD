How to Pick a Gear Set

Choose a set whose trigger matches what your Martial Arts actually do in combat. Fast multi-hit styles, shield-focused builds, evasive setups and support builds all value different bonuses. Check the current in-game tooltip for exact numeric values before spending rare upgrade materials.
