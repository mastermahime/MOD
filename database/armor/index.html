How to Use This Page

Use the table to pick a set whose trigger matches the way your Martial Arts actually play. Then verify the exact numeric bonus on the item tooltip for your current gear tier and patch before committing rare upgrade materials.

The archive summarizes mechanics in original wording rather than copying another wiki's descriptions. Patch-sensitive values should always be checked against the current in-game tooltip.
