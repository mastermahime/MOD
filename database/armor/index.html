How Set Bonuses Work

Offensive sets occupy the two weapon slots plus Disc and Pendant-style accessory slots. Defensive sets use the four armor pieces. Equipping two matching pieces activates the smaller stat bonus; four matching pieces unlock the defining mechanic.

Localization has changed some names across versions and community references. The current database uses Global terminology where verified and keeps a familiar alternate name when it helps players find the set.
