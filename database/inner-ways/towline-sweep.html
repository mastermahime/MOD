Bamboocut - Dust

Towline Sweep

Unfettered Rope Dart passive that improves Soul Sweep, Soul Loss and pulling utility.

Effect

Soul Sweep generates Tokens of Gratitude, while Piercing Dart applies additional Soul Loss and the first sweep can pull enemies.

How to Obtain

Complete the Desert Without Sails progression in the western region.

Build Use

A core Bamboocut - Dust option for Rope Dart control and resource generation.
