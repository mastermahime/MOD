Mystic Skill

Lion's Roar

A sound-based technique earned by finding and ringing a set of copper bells.

How to Unlock

Locate and ring four distinct copper bells across Qinghe. Progress is tied to unique bells, so repeatedly using the same bell will not complete the route.

Tip

Treat this as an exploration unlock. Mark bells as you find them so you do not waste time revisiting the same location.
