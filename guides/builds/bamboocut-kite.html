Default Martial Path

Bamboocut - Kite uses Skygrasp Rope Dart to control the engagement, then Heavenwill Gauntlets convert that setup into close-range burst.

Recommended Inner Ways

Gear Focus

Etherwrath is the natural offensive option for sustained trigger pressure. Honorbound is a strong defensive choice when you consistently Perfect Dodge.

Suggested Mystic Skills

Dragon's BreathCloud StepsTai ChiGolden Body

How to Play

  1. Use Skygrasp Rope Dart to control distance and create the opening.
  2. Swap into Heavenwill Gauntlets only when you can stay close long enough to use the burst window.
  3. Perfect Dodge dangerous strings instead of greedily extending damage.
  4. Return to Rope Dart when the target moves outside your ideal Gauntlet range.
